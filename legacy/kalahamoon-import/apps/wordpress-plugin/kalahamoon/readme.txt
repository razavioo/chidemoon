Connect WordPress to Kalahamoon for product publishing, affiliate links, tracked CTAs, and AI-assisted comparisons.

== Description ==

Kalahamoon helps publishers and commerce teams display synced products, generate affiliate links, track clicks, and build RTL-first product recommendation blocks directly in WordPress.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/kalahamoon` or install the plugin archive.
2. Activate Kalahamoon from the WordPress Plugins screen.
3. Open Kalahamoon > Settings and connect your Kalahamoon account.
4. Sync products and start using the Kalahamoon blocks or shortcodes.

== Frequently Asked Questions ==

= Does Kalahamoon require a Kalahamoon account? =

Yes. Product sync, affiliate links, and connected analytics require a Kalahamoon account.

= Does it support RTL sites? =

Yes. The plugin is RTL-first and uses WordPress locale/direction helpers throughout admin and frontend surfaces.
