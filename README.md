# چیدمون با المنتور

قالب فعال سایت **Hello Elementor** است. صفحه‌ها و قالب‌های عمومی در دادهٔ بومی المنتور ذخیره می‌شوند. بلاکسی، قالب فرزند، رندرهای قدیمی صفحات و نسخهٔ منقرض‌شدهٔ افزونهٔ قبلی حذف شده‌اند؛ سابقهٔ آن‌ها در Git در دسترس است.

## ویرایش روزمره

| بخش | محل ویرایش |
| --- | --- |
| صفحهٔ اصلی، راهنماها، مقایسه‌ها، ایده‌های چیدمان | برگه‌ها → ویرایش با المنتور |
| سربرگ و پاورقی | قالب‌ها → Theme Builder → Header / Footer |
| ظاهر نوشته‌ها | Theme Builder → Single Post |
| مجله و دسته‌های مطلب | Theme Builder → Archive |
| جست‌وجو و ۴۰۴ | Theme Builder → Search Results / Error 404 |
| جزئیات و دستهٔ محصول | Theme Builder → Product / Product Archive |
| رنگ و فونت مشترک | المنتور → Site Settings |
| متن راهنما و مقایسهٔ تحریریه | نوشته‌ها → ویرایشگر وردپرس |
| تصویر و نقاط چیدمان | نوشتهٔ چیدمان → المنتور → Chidemoon Shop the Look |
| نام، تصویر، قیمت و مشخصات محصول | محصولات → ویرایش محصول |

در ویجت چیدمان، محصول با نام قابل جست‌وجو است؛ موقعیت نقطه با دو کنترل درصدی تنظیم می‌شود. تب Style رنگ، اندازهٔ نقاط، پنل، تصویر و زیرنویس را کنترل می‌کند. در ویجت مقایسه، متن جست‌وجو و حالت خالی، تعداد ستون‌ها، عرض ورودی، فاصله، رنگ و تایپوگرافی کارت‌ها، جدول و دکمه‌ها قابل تغییرند. ویجت اطلاعات محصول، متن و تراز و عرض دکمه، نمایش منبع، عنوان فروشنده، مشخصات و پیام قیمت را کنترل می‌کند. جست‌وجوی سربرگ و صفحهٔ نتایج ویجت بومی Search المنتور پرو است؛ ستون‌ها و لینک‌های فوتر نیز عناصر بومی‌اند.

منطق تأیید محصول، ارجاع `/go/{id}/` و انتخاب مقایسه در `chidemoon-core` است. لینک خرید فقط برای محصول منتشر شدهٔ External/Affiliate با وضعیت Reviewed و نشانی معتبر فعال می‌شود. سبد خرید، حساب و تسویه به فهرست محصولات هدایت می‌شوند. تصاویر چیدمان مفهومی‌اند؛ تصاویر محصولات واقعی از منبع فروشنده وارد رسانه‌ها می‌شوند.

تاریخ‌های نمایشی با تقویم فارسی ICU و منطقهٔ زمانی سایت نمایش داده می‌شوند. تاریخ ذخیره‌سازی، API، خوراک و ورودی استاندارد تاریخ برای سازگاری با وردپرس ISO/میلادی می‌مانند. افزونهٔ PHP `intl` لازم است و در تصویر سرور موجود است. آزمون `php tests/jalali-dates.php` مرز نوروز، سال کبیسه و حفظ تاریخ ماشینی را بررسی می‌کند.

## نصب و بازسازی

Core و Pro المنتور باید به‌صورت جفت سازگار و دارای مجوز نصب شوند. نسخه‌های آزموده‌شدهٔ اولیه Core 4.2.4 و Pro 4.2.3 هستند. آرشیو Hello 3.5.1 و ووکامرس با checksum در `vendor` هستند؛ بسته و کلید تجاری المنتور در Git یا انتشار قرار نمی‌گیرد.

برای محیط تازه، `standalone-init.ps1` برگه‌ها، رسانه‌ها و قالب‌های المنتوری را می‌سازد. گزینهٔ `-Seed` فقط مجموعهٔ تازهٔ تحریریه را اضافه می‌کند. ZIPهای خصوصی مورد نیاز را می‌توان به‌صورت محلی در `vendor` قرار داد یا قبلاً در وردپرس نصب کرد.

بازسازی نصب موجود، پس از تهیهٔ نسخهٔ بازگشت و در محیط آزمایشی:

```sh
wp --user=1 eval-file /tools/elementor-rebuild.php
wp --user=1 eval-file /tools/elementor-rebuild.php apply reset-demo
wp --user=1 eval-file /tools/rebuild-editorial.php
wp theme activate hello-elementor
wp --user=1 eval-file /tools/verify-elementor.php
```

دستور اول فقط گزارش می‌دهد. `reset-demo` فقط یک بار فهرست قبلی نوشته‌ها و محصولات منتشر شده را به زباله‌دان منتقل می‌کند. اجراهای بعدی تغییرات کاربر را حفظ می‌کنند. **`force` قالب‌ها، برگه‌ها و تنظیمات مشترک را بازنویسی می‌کند** و برای ویرایش روزمره استفاده نمی‌شود. رسانه‌های لازم در محیط تازه از تصاویر همراه وارد می‌شوند.

## انتشار و بازگشت

`ops/create-release-bundle.sh` از commit تمیز بستهٔ دارای checksum می‌سازد. قبل از انتشار، `node --test tests/*.test.mjs`، بررسی PHP و `tools/verify-elementor.php` اجرا شوند. تغییرات داده و فعال‌سازی Hello باید در همان پنجرهٔ انتشار انجام شوند؛ تغییر symlink به‌تنهایی مهاجرت پایگاه داده را برنمی‌گرداند.

برای اولین مهاجرت نصب موجود، `bash ops/deploy-elementor-rebuild.sh <source.tar.gz> <images.tar.gz>` استفاده می‌شود. این دستور پیش از تغییر سایت از پایگاه داده و رسانه‌ها نسخه می‌گیرد، حالت نگهداری را فعال می‌کند، قالب‌ها را می‌سازد و پس از آزمون Hello سایت را باز می‌کند. شکست مهاجرت، release و پایگاه دادهٔ قبلی را برمی‌گرداند. انتشارهای بعدی با `ops/deploy-release-bundle.sh` انجام می‌شوند و داده‌های ویرایش‌شدهٔ المنتور بازنویسی نمی‌شوند.

برای بازطراحی مصوب این نسخه، `CHIDEMOON_VISUAL_REFRESH=1` به دستور مهاجرت اضافه می‌شود. `CHIDEMOON_IMPORT_VERIFIED_CATALOGUE=1` چهار پیشنهاد واقعی ثبت‌شده در ۷ مهر ۱۴۰۵ را وارد می‌کند. ورودی در `tools/catalogue/verified-products.json` و خروجی checksumدار در `verified-products.export.json` است؛ بازسازی خروجی با `node tools/build-import-export.mjs --input tools/catalogue/verified-products.json --output tools/catalogue/verified-products.export.json --organization-slug chidemoon --generated-at 2026-09-29T15:05:00Z` انجام می‌شود. هر محصول تصویر اصلی، دو تصویر گالری، توضیح، مشخصات، فروشنده و منبع دارد. قیمت‌ها تومان و ثبت‌شده‌اند، نه قیمت زنده؛ ثبت وضعیت Reviewed به معنی بررسی اطلاعات منبع است و ادعای تست عملی محصول ندارد. اجرای دوباره با sourceKey همان محصول را به‌روز می‌کند.

بازگشت کامل نیاز به release قبلی، نسخهٔ پایگاه داده و رسانه‌ها دارد. برای این بازسازی، نسخهٔ اولیه روی میزبان در `/opt/chidemoon/backups/elementor-rebuild-20260929` نگهداری می‌شود. مرحلهٔ آزمایشی پایگاه داده و volume مستقل دارد و با تولید مشترک نیست.

## هوش مصنوعی

اتصال AI به ادیتور طبق پلن این بازسازی به مرحلهٔ بعد موکول شده است. افزونهٔ AI موجود فعال می‌ماند، اما خروجی آن به‌خودی‌خود چیدمان بومی المنتور تولید نمی‌کند. اتصال آینده باید درج عناصر ساختاریافته، پیش‌نمایش و تأیید کاربر را پیاده کند. کلید سرویس‌دهنده و ارتقای سازگار نسخه‌ها پیش‌نیاز آزمون تولید واقعی خواهند بود.
